- **CI's `eval` job no longer fails when the model cache is cold.** It ran `pnk doctor` before the evaluation, but since 0.32.9 `pnk doctor` loads models offline and downloads none, and `pnk sync` loads only the embedder, so the reranker had not reached the cache: the first run after the cache expired failed on `FAIL reranker`, and a failed job skips the cache's save step. The evaluation, which loads the reranker, now runs first, and `tests/test_ci_eval_job.py` pins the order. Reproduced on an empty model cache with the job's own three commands: the old order exits 1 at `pnk doctor`, and the same cache passes once the evaluation has run. No code under `src/` changed.
